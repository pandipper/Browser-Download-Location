## 要解决的问题

改浏览器的下载目录，意味着打开浏览器、翻设置、粘贴路径 —— 每次都要来一遍。本工具把它
变成一次右键：标记一个文件夹，下载就开始落到那里。

麻烦的地方不是设置页，而是 Chromium 把下载路径**放在内存里**，并按自己的时机重写
`Preferences` 文件。在开发机上实测：Edge 运行时写入的值，大约 **7 秒后**就被覆盖了。
所以这个文件只有在浏览器确实没在运行时才写得进去 —— 而「关掉了所有窗口」并不等于
「没在运行」。

另外三条路子都实测过，在这里都是死路：

| 路径 | 为什么不行 |
| --- | --- |
| `edge://restart` | 它不会关闭任何东西。 |
| 浏览器扩展 | Chromium 刻意不提供任何能更改默认下载目录的 API。 |
| 非管理员写 `HKCU\SOFTWARE\Policies` | 在开发账户上，那个键连**读**都不行，更别说写。 |

## 功能

- **一次右键**即可把任意文件夹标记为下载位置。
- **立即放入一个隐藏标记**（小旗帜图标），一眼就能看出当前目标是哪个文件夹。
- **自动关闭浏览器、写入新路径、读回来确认、再重新打开浏览器**。事后无需任何验证。
- **绝不打断正在进行的下载**（会先检查 `.crdownload`）。
- **自己收拾干净**：无论重新标记多少次，磁盘上始终只有一个标记文件。
- 支持 **Edge、Chrome 和 Brave**（自动检测），默认路径**不需要管理员权限**。

## 快速开始

1. 把本仓库下载或克隆到任意位置。
2. 双击 **`Setup.cmd`**，选 **`1`**（安装全部）。
3. 在资源管理器里右键任意文件夹，选择 **「设为浏览器下载位置」**。
4. 完成。该文件夹现在就是下载位置，浏览器会自行重新打开。

## 两种通道

| | **文件通道** | **策略通道** |
| --- | --- | --- |
| 方式 | 重写浏览器自己的 `Preferences` | 设置 Windows 的 `DownloadDirectory` 策略 |
| 管理员 | 不需要 | **需要** |
| 需关闭浏览器 | **是** | 不需要，几秒内生效 |
| 副作用 | 无 | 下载设置变灰 / 显示「由你的组织管理」 |
| 用于 | 选项 5、6，以及右键菜单 | 选项 7 |

`-Mode auto`（默认）在本窗口已提权时走策略通道，否则走文件通道。

## 工作原理

标记一个文件夹会按顺序做四件事：

1. **放入标记**，并把它从本工具标记过的其它所有文件夹里移除。
2. **请打开的窗口关闭** —— 一个普通的 `WM_CLOSE`，所以会话会被保存。
3. **终止仍在运行的一切。** 这比听起来更重要：见下面的启动加速说明。
4. **写入新路径、读回来、重新打开浏览器。**

### 为什么「关掉浏览器」还不够

Edge 的**启动加速**会在最后一个窗口关闭后，继续保活一个无窗口进程。本机实测：
**0 个窗口打开，11 个进程仍存活**。那个进程内存里握着旧的下载目录，所以它稍后会悄悄把
新值覆盖回去。关窗口对它毫无作用。

所以本工具最多等 **5 秒**让窗口退出（且只在确实有窗口打开时才等），然后终止剩余的进程。
强杀不写任何设置，所以旧值回不来。

### 标记的记账

本工具标记过的每个文件夹都记录在 `markers.txt` 里，除当前目录外，标记会从所有目录中
移除。只看最后一次**已应用**的目录是不够的：变更还在排队时，那个目录根本不前进，于是
每再标记一次就多遗留一个标记 —— 早期版本正是这样堆出一地 `.ico` 文件的。

## 命令行

```powershell
# 标记一个文件夹（会关闭浏览器并应用）
.\Set-DownloadFlag.ps1 'D:\Downloads\Browser'

# 报告当前位置、已标记的目录，以及待处理的变更
.\Set-DownloadFlag.ps1 -Show

# 标记但不关闭浏览器
.\Set-DownloadFlag.ps1 -WaitOnly 'D:\Downloads\Browser'

# 强制走策略通道（需要已提权的窗口）
.\Set-DownloadFlag.ps1 -Mode policy 'D:\Downloads\Browser'

# 移除标记、清除标志、取消待处理的变更
.\Set-DownloadFlag.ps1 -Unflag

# 清理早期版本遗留的标记文件
.\Set-DownloadFlag.ps1 -Cleanup

# 移除下载策略并解锁浏览器设置
.\Set-DownloadFlag.ps1 -RemovePolicy
```

| 参数 | 含义 |
| --- | --- |
| `-Target <路径>` | 要标记的目录（位置参数）。 |
| `-Show` | 报告状态。 |
| `-Unflag` | 清除标志并取消。 |
| `-Cleanup` | 清理残留的标记文件。 |
| `-Browser auto\|Edge\|Chrome\|Brave` | 哪个浏览器。 |
| `-Mode auto\|policy\|file` | 以何种方式应用。 |
| `-WaitOnly` | 不关闭浏览器。 |
| `-Elevate` | 通过 UAC 提示重新启动。 |
| `-RemovePolicy` | 删除本工具设置的策略。 |
| `-NoPause` | 跳过关闭前的 3 秒倒计时。 |

## 常见问题

**目录没有变。**
运行选项 **4** —— 它会报告待处理的变更以及是什么在阻塞它。如果浏览器开着启动加速，
在 `edge://settings/system` 关掉它，或者直接用选项 6（默认），它会替你关闭浏览器。

**残留了好几个 `.ico` 文件。**
运行选项 **9**。它会清除标记并清理本工具标记过的所有目录。

**「你的浏览器由你的组织管理」。**
那是策略通道（选项 7）造成的。在个人电脑上，它仅意味着设置了本地策略。选项 **8** 可以移除它。

**下载设置变灰了。**
同一个原因。运行选项 **8** 解锁。

**过一会儿下载又落到别的目录了。**
写入变更时浏览器仍在运行。请用选项 6，或者关闭启动加速。
